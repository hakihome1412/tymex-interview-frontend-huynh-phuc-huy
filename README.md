## Project Structure

```
│   ├── utils/             # Utility functions

│   └── main.tsx           # Application entry point
├── public/                # Public assets
├── dist/                  # Build output
└── ...                    # Config files
```

## Getting Started

### Installation

**Using npm:**
```bash
npm install
```

**Using yarn:**
```bash
yarn install
```

**Using bun:**
```bash
bun install
```

### Development

**Using npm:**
```bash
npm run dev
```

**Using yarn:**
```bash
yarn dev
```

**Using bun:**
```bash
bun run dev
```

### Build

**Using npm:**
```bash
npm run build
```

**Using yarn:**
```bash
yarn build
```

**Using bun:**
```bash
bun run build
```
